# 智能识别与定级 · 演示 v5

将整个“演示v5”文件夹复制到演示电脑本地磁盘，Windows 双击 **启动演示.bat**（或 start.bat）。脚本会导入镜像、启动网页及聚类服务、等待模型校验完成，然后自动打开 http://localhost:3001。

## 演示电脑准备

- Windows 电脑预先安装并启动 Docker Desktop，使用 Linux containers 模式；不需要安装 Node.js、Python 或下载本地聚类模型。
- 镜像为 linux/amd64，适用于常见 Intel / AMD Windows 电脑。建议 16 GB 内存，Docker 至少分配 8 GB，磁盘至少预留 15 GB；首次导入与启动需要数分钟。
- macOS / Linux 可运行 `bash start.sh`。Apple Silicon 需要 Docker 的 amd64 模拟，速度与兼容性未在本机验证。

## 演示步骤

1. 双击“启动演示.bat”，等待浏览器自动打开。
2. 如需图片 AI 识别，在“模型配置”页面填写可用的视觉模型 Base URL、API Key 和模型名，测试连通后保存。此功能需要能访问模型 API 的网络；包内未携带私人 API Key，也不会生成假的识别结果。
3. 可选择内置图片样例进行识别；聚类展示 / 聚类测试使用包内的 BGE 中文模型，可在断网时运行。
4. 演示结束双击“停止演示.bat”。再次启动无需重复导入已存在且匹配的镜像。

## 常用操作

- 查看日志：双击 logs.bat。
- 端口被占用：在此文件夹终端运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -Port 3014`，使用 http://localhost:3014。
- 无 Docker 命令：安装 Docker Desktop 后重新打开脚本；Docker 尚未就绪时，脚本会尝试启动并等待。
- 启动超时：查看 logs.bat，检查 Docker 内存、Linux containers 模式以及磁盘空间。

## 文件与数据

- `hazard-demo-v5.tar`：网页 / API 与 Python 聚类两份镜像的离线归档，含本地模型。
- `images.json` / `images.sha256`：镜像标识和归档校验值。
- `compose.yaml`：两套服务的启动与健康检查配置；只向本机开放网页端口。
- `data/`：首次启动创建，保存模型配置、导入规则和聚类作业。停止服务不会删除这些数据。配置 API Key 后，此文件夹会包含该 Key，请自行保管。
- 隐患识别历史等前端数据保存在当前浏览器的 localStorage 中，换电脑 / 浏览器 / 端口不会自动迁移；需要时先从页面导出。

此包使用项目当前的演示入口，无需 GitHub 登录。包含当前工作区尚未提交的功能。聚类为 CPU 运行，适合先用内置的 50 条数据演示；大规模任务耗时取决于演示电脑性能。

## 维护与重新打包

仓库中的 deploy/demo-v5/package.ps1 可重新构建并导出此演示包；已构建好镜像时可加 -SkipBuild。Python 镜像包含本地模型和已校验的知识索引，构建前需保留仓库内相应文件。source-model.json 是该知识索引的原始模型配置，用于验证迁移前后仅磁盘路径发生变化。日常演示不需要运行打包脚本。

21 个聚类配置均可用，内置 50 条语义聚类首次运行约 1 分钟，目标电脑耗时可能不同。
